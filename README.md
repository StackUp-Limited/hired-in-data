# Hired in Data sites

| Folder | Site | Vercel project |
|---|---|---|
| `root/` | hiredindata.com (incl. /testimonials, lead magnets, `api/` form handlers) | hiredindata-root |
| `mandy/` | mandy.hiredindata.com | hiredindata-mandy |

Static HTML, no build step. Each Vercel project points at this repo with its Root Directory set to the matching folder, so pushing to `main` redeploys both.

Note: the pages were originally generated by a build script (`build.js` + `content.json`) that isn't in this repo. Edits here are made to the HTML directly.
