# Hired in Data sites

| Folder | Site | Vercel project |
|---|---|---|
| `root/` | hiredindata.com (incl. /testimonials, lead magnets, `api/` form handlers) | hiredindata-root |
| `mandy/` | mandy.hiredindata.com | hiredindata-mandy |
| `egor/` | egor.hiredindata.com, egorhowell.com (workshop.egorhowell.com redirects to the webinar) | hiredindata-egor |

Static HTML, no build step. Each Vercel project points at this repo with its Root Directory set to the matching folder, so pushing to `main` redeploys all of them.

Note: the pages were originally generated by a build script (`build.js` + `content.json`) that isn't in this repo. Edits here are made to the HTML directly.

## Making changes
Push to `main` and Vercel redeploys all three projects automatically (each one only builds its own folder). Check the deployments in Vercel if a site looks wrong; any earlier deployment can be promoted back with one click.
